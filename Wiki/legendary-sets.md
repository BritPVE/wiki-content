# Legendary Sets

Legendary Sets provide powerful bonuses that can significantly improve your performance, whether you're farming resources, tackling PvE events, or raiding.

## Quick Overview

- **Recommended For:** Mid to End Game
- **Main Goal:** Choose the right legendary set for your preferred playstyle.

| Set | Type | Best For |
|---|---|---|
| Leviathan Armor | Combat | Patrol Helis, Harbinger, Deep Sea, high-end PvE |
| Impact Guard Armor ("Impact set") | Combat | Mid-game PvE, Patrol Helis, Bradley |
| Dragon Thorns Armor | Combat | Scientists, long PvE fights, solo players |
| Mining / Lumberjack / Hunter / Farmer / Scavenger / Angler Set | Resource | Quartermaster tasks and RP farming |
| Skiller Set | Resource | All of the above in one set |
| Helping Hands | Special | Auto-revive when downed |

Drop sources on this page come from the wiki's **[Item Drops](/loot-tables)** page, which is generated from the server's loot tables. Exact drop chances are not published by the developers.

## Combat Sets

### Leviathan Armor

![Leviathan Chest Plate](/api/lookup/skins/3322499121/image)

The strongest defensive legendary armor currently available.

**Best For**
- Patrol Helis
- Harbinger
- Deep Sea
- High-end PvE

#### Set Bonus

Provides approximately **53% Impact Absorption** with the full set.

| Pieces Equipped | Impact Absorption |
|----------------:|------------------:|
| 1 | 33% |
| 2 | 36% |
| 3 | 38% |
| 4 | 41% |
| 5 | 44% |
| 6 | 46% |
| Full Set | **53%** |

**Drop sources:** Deep Sea cargo (locked, elite and military crates, junk piles, and the scientists on board); Deep Sea and patrol boat scientists; patrol boat crates; Cobalt Assault (legendary crate, scientists); Large Presents. Leviathan does **not** drop from Patrol Helis, Bradleys, Dungeons or Raidable Bases.

> 💡 **Tip**
>
> Leviathan is currently the strongest defensive armor set available and is considered a direct upgrade over the Impact Guard set.

### Impact Guard Armor

![Impact Guard Chest Plate](/api/lookup/skins/2761257302/image)

A defensive legendary armor set focused on reducing incoming damage. Players usually just call it the **Impact set**.

**Best For**
- Mid-game PvE
- Patrol Helis
- Bradley

#### Set Bonus

Provides approximately **33% Impact Absorption** with the full set.

| Pieces Equipped | Impact Absorption |
|----------------:|------------------:|
| 1 | 13% |
| 2 | 16% |
| 3 | 18% |
| 4 | 21% |
| 5 | 24% |
| 6 | 26% |
| Full Set | **33%** |

**Drop sources:** Patrol Helis (every tier, with higher tiers dropping the chest and facemask); Bradley locked crates (Hard, Elite); Raidable Bases (Hard); Dungeons (Medium, Hard, Nightmare); Deep Sea cargo (elite crates); Boss Drone (locked crate); Cobalt Assault (legendary crate); Dome Event (hackable and heli crates); Sat Dish Event (elite and hackable crates); world crates (pants only); Large Presents.

### Dragon Thorns Armor

![Dragon Thorns Cloak](/api/lookup/skins/3216813583/image)

A legendary armor set that restores health while dealing damage.

**Best For**
- Scientists
- Long PvE fights
- Solo players

#### Set Bonus

Provides **12.5% Vampiric Healing** with the full set.

| Piece | Bonus |
|-------|------:|
| Facemask | 1% |
| Hoodie | 2% |
| Cloak | 7% |
| Gloves | 1% |
| Boots | 1% |
| Pants | 0.5% |

**Drop sources:** Boss Drone, Cobalt Assault (legendary crate) and Large Presents can drop every piece. Individual pieces also drop from Bradley locked crates (Easy, Medium), Dungeons (Easy, Normal, Medium), Raidable Bases (Easy, Medium) and Patrol Helis (Hard, Multi Hard).

## Resource & Farming Sets

These legendary sets are designed to maximize resource gathering and are highly recommended for Quartermaster tasks and RP farming.

| Set | Best For | Full Set Bonus |
|------|----------|---------------:|
| **Mining Set** | Stone, Metal & Sulfur | +100% Ore Yield |
| **Lumberjack Set** | Wood | +100% Wood Yield |
| **Hunter Set** | Animals & Bone Fragments | +100% Yield |
| **Farmer Set** | Crops | +60% Crop Yield |
| **Scavenger Set** | Barrels & Road Farming | +60% Yield |
| **Angler Set** | Fishing | +200% Fishing Efficiency |
| **Skiller Set** | All | All of the above in one set |

The Mining, Lumberjack, Hunter, Farmer, Scavenger and Angler sets each have three pieces: **Hat**, **Chest** and **Pants**.

**Drop sources (Mining, Lumberjack, Hunter, Farmer, Scavenger, Angler):** normal and military world crates, Deep Sea cargo junk piles, and Raidable Base boxes (each piece is tied to a specific raid difficulty).

**Drop sources (Skiller):** only the Hat and Pants appear in the loot tables. The Hat drops from Canon crates; the Pants drop from Cobalt Assault scientists, Deep Sea scientists and patrol boat scientists.

> 💡 **Tip**
>
> Most resource and farming sets can be obtained through the **Underground Tunnels**, making them relatively easy to acquire early in your progression.

## Special Legendary Gear

### Helping Hands

![Helping Hands](/api/lookup/skins/3622432427/image)

A unique legendary item that automatically revives you when downed.

**Effect**
- Instantly revives you with **full health**.
- Grants **5 seconds of invulnerability** after reviving.

This makes Helping Hands one of the strongest survival items available, especially during difficult PvE encounters and boss fights.

**Drop sources:** Raidable Bases (Expert, Nightmare); Dungeons (Hard, Nightmare); Deep Sea cargo (locked crates); Boss Drone (locked crate); Cobalt Assault (legendary crate); Large Presents.
