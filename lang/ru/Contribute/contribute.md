# Хотите внести свой вклад?

Используйте эту страницу, чтобы предлагать обновления контента для вики через Pull Request'ы на GitHub.

[Открыть репозиторий wiki-content](https://github.com/BritPVE/wiki-content)

## Как отправить Pull Request (PR)

1. Сделайте **Fork** репозитория `BritPVE/wiki-content` на свой аккаунт GitHub.
2. Создайте новую ветку для ваших изменений.
3. Отредактируйте страницу в `lang/en/` (например, `lang/en/Wiki/`). Добавьте соответствующий перевод по тому же пути в `lang/<code>/`.
4. Сделайте коммит с понятным описанием внесенных изменений.
5. Откройте Pull Request в основную ветку `BritPVE/wiki-content:main`.
6. Опишите в описании PR краткую суть ваших правок.

## Как устроена навигация (Меню)

Боковое меню вики настраивается файлом `navigation.json` в корне репозитория. Файлы страниц берутся из папки `lang/en/`, однако **они не появятся в меню сайта, пока вы не добавите их в `navigation.json`**.

Английский язык является языком по умолчанию. Переводы зеркально повторяют структуру папок в `lang/<code>/`. Например, `lang/en/Wiki/skills.md` переводится файлом `lang/ru/Wiki/skills.md`. Файл `overview.md` лежит на одном уровне с папками разделов: `lang/en/overview.md`.

Поле `name` раздела или категории представляет собой объект с языковыми кодами (`en`, `ru`, `tr` и т.д.). Имена файлов страниц остаются неизменными во всех локалях. Не создавайте отдельные разделы для каждого языка.

При добавлении новой страницы:

1. Добавьте файл на английском в `lang/en/` (например, `lang/en/Wiki/my-new-page.md`).
2. Откройте `navigation.json` и добавьте слаг страницы в массив `pages` нужной категории.
3. Используйте имя файла без расширения (например, `my-new-page`).
4. Расположите страницы в массиве в том порядке, в котором они должны отображаться в боковом меню.
5. Для перевода добавьте файл `lang/<code>/Wiki/my-new-page.md` и переведите название категории в `navigation.json` при необходимости.

Пример категории в `navigation.json`:

```json
{
  "name": { "en": "Guides", "ru": "Гайды", "tr": "Rehberler" },
  "pages": [
    "beginner-guide",
    "my-new-page"
  ]
}
```

Чтобы временно скрыть страницу из меню без её удаления, добавьте её слаг в массив `hiddenPages` в файле `navigation.json`.

Название страницы в меню формируется из её первого заголовка `# Название`, а URL выглядит как `/wiki/<slug>`. Называйте файлы в нижнем регистре через дефис (`my-new-page.md`).

## Правила форматирования на сайте

Сайт вики использует стандартный Markdown, однако есть несколько важных нюансов, которые необходимо соблюдать:

**Изображения**

- Храните изображения в папке `assets/` в корне репозитория и ссылайтесь на них с относительным путем, **обязательно включая расширение файла**: `![Steak Dinner](../../../assets/AllMeals/SteakDinner.png)`. Путь без расширения приведет к ошибке отображения.
- Пути к файлам **чувствительны к регистру**: `BlueBerry.png` и `Blueberry.png` — это разные файлы.
- Всегда заполняйте альтернативный текст в квадратных скобках `![Текст]`.
- Иконки предметов и скинов можно вставлять напрямую через встроенный API поиска: `![Name](/api/lookup/skins/<skinId>/image)` или `![Name](/api/lookup/items/icon/<itemId>)`. ID скинов можно найти на странице **[Дроп предметов](/loot-tables)**.

**Ссылки между страницами**

- Ссылайтесь на другие страницы вики через абсолютный путь: `[Навыки](/wiki/skills)`. Ссылки на внутренние якоря разделов (`#section`) **не поддерживаются**.
- Инструменты сайта: `/loot-tables` (Дроп предметов) и `/xp-calculator` (Калькулятор XP).

**Блоки цитат и сворачиваемые блоки**

- Для подсказок и предупреждений используйте стандартные цитаты blockquote:

```markdown
> 💡 **Совет**
>
> Текст полезного совета.

> ⚠ **Важно**
>
> Текст важного предупреждения.
```

- Синтаксис GitHub Alerts `> [!NOTE]` **не поддерживается**.
- Сворачиваемые списки используют теги `<details>` и `<summary>`. Обязательно оставляйте **пустую строку** после `</summary>` и не делайте отступов у содержимого:

```markdown
<details>
<summary><strong>Показать подробнее</strong></summary>

![Image](../../../assets/example.png)

</details>
```

**Таблицы и видео**

- Всегда оставляйте пустую строку перед таблицей и после неё.
- Вставка видео с YouTube осуществляется конструкцией: `@[youtube](https://www.youtube.com/watch?v=VIDEO_ID){width=960 height=540}`
