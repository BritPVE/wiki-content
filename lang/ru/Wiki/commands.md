# Команды сервера (Commands)

На серверах Brits PvE Worlds добавлено множество кастомных команд, которые значительно упрощают перемещение по мирам, торговлю, автоматизацию и повседневное выживание.

## Краткий обзор

- **Кому подходит:** Всем игрокам.
- **Главная цель:** Изучить наиболее полезные и часто используемые команды.
- **Подсказка:** Список основных команд доступен прямо в игре через команду **`/info`**.

Все команды вводятся в чат (нажав Enter). Для самых частых команд настройте бинды клавиш (подробная инструкция внизу страницы).

---

## Основные команды (Essential)

Команды, которые должен знать каждый новичок:

| Команда | Описание |
|---|---|
| `/hub` | Мгновенный телепорт в центральный ХАБ |
| `/w` или `/worlds` | Открыть меню выбора миров (World Menu) |
| `/q` или `/quest` | Открыть меню заданий (Квестов) |
| `/s` | Открыть главный магазин и биржу ресурсов (Stock Market) |
| `/st` | Открыть Древо навыков (Skill Tree) |
| `/kit` | Забрать бесплатные стартовые наборы (привязка Discord дает доп. киты) |
| `/sell` | Продать ресурсы за валюту RP |
| `/pricecheck <предмет>` или `/pc <предмет>` | Проверить текущую цену скупки предмета (цены различаются между мирами!) |
| `/vq` или `/qr` | Открыть меню Виртуальных карьеров |
| `/tod` | Узнать текущее внутриигровое время суток |
| `/wa` | Открыть меню личного тайника и Достижений вайпа (Wipe Achievements) |
| `/info` | Внутриигровое окно помощи со списком доступных команд |
| `/wiki` | Информационное окно вики прямо в игре |

## Доступ и разрешения (Sharing)

На Brits PvE всё, что вы ставите, защищено: чужие игроки не могут трогать ваши вещи. Если вы хотите поделиться доступом с другом:

| Команда | Описание |
|---|---|
| `/share` | Открыть доступ ко всем вашим объектам для всех игроков |
| `/share <ник>` | Дать доступ конкретному игроку |
| `/unshare` | Закрыть общий доступ |
| `/unshare <ник>` | Забрать доступ у конкретного игрока |
| `/sharelist` | Посмотреть список игроков с доступом |
| `/autoauthui` | Настроить автоматическую авторизацию в турелях/шкафах |

## Настройка биндов клавиш (Keybinds)

Бинды позволяют вызывать команды чата нажатием одной кнопки без необходимости каждый раз открывать чат и печатать текст.

Откройте консоль клавишей **F1** и введите команду по шаблону:

```text
bind клавиша chat.say "/команда"
```

Для команд без пробелов кавычки можно не ставить:

```text
bind клавиша chat.say /команда
```

Чтобы бинд сохранился после перезапуска игры, Facepunch рекомендует ввести в консоль:

```text
writecfg
```

Чтобы удалить бинд с клавиши:

```text
bind клавиша ""
```

### Рекомендуемые примеры биндов:

| Назначение | Команда | Рекомендуемая клавиша | Команда в консоль F1 | Удаление бинда |
|---|---|---|---|---|
| Возврат в ХАБ | `/hub` | Numpad `+` | `bind numpadplus chat.say /hub` | `bind numpadplus ""` |
| Телепорт домой | `/home <название>` | Numpad `-` | `bind numpadminus chat.say "/home main"` | `bind numpadminus ""` |
| Меню квестов | `/q` | Numpad `9` | `bind numpad9 chat.say /q` | `bind numpad9 ""` |
| Виртуальные карьеры | `/vq` | Numpad `6` | `bind numpad6 chat.say /vq` | `bind numpad6 ""` |
| Купить рейд-базу | `/buyraid` | Numpad `7` | `bind numpad7 chat.say /buyraid` | `bind numpad7 ""` |
| Купить данж | `/buydungeon` | Numpad `8` | `bind numpad8 chat.say /buydungeon` | `bind numpad8 ""` |
| Магазин / биржа | `/s` | Запятая `,` | `bind comma chat.say /s` | `bind comma ""` |
| Бесплатный велосипед | `/toolazytowalk` | Левая скобка `[` | `bind leftbracket chat.say /toolazytowalk` | `bind leftbracket ""` |
| Древо навыков | `/st` | Правая скобка `]` | `bind rightbracket chat.say /st` | `bind rightbracket ""` |
| Принять телепорт | `/tpa` | Точка `.` | `bind period chat.say /tpa` | `bind period ""` |

Если на вашей клавиатуре нет блока NumPad (TKL или ноутбук), используйте квадратные скобки `[` и `]`, точку `.`, точку с запятой `;` или апостроф `'`.
