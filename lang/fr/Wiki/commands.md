# Commandes

Brits PvE Worlds ajoute de nombreuses commandes personnalisées qui rendent les déplacements, la progression, l'automatisation et le gameplay beaucoup plus simples.

## Aperçu rapide

- **Recommandé pour :** tous les joueurs
- **Objectif principal :** apprendre les commandes les plus utilisées.
- **Astuce :** la plupart des commandes se trouvent aussi en jeu avec **`/info`**.

Toutes les commandes se tapent dans le chat. Si vous utilisez une commande en permanence, associez-la à une touche : voir **Associer des commandes à des touches** en bas de cette page.

---

## Commandes essentielles

Ce sont les commandes que chaque nouveau joueur devrait connaître.

| Commande | Description |
|----------|-------------|
| `/hub` | Se téléporter au HUB |
| `/w` ou `/worlds` | Ouvrir le menu des mondes |
| `/q` ou `/quest` | Ouvrir le menu des quêtes |
| `/s` | Ouvrir la boutique / le Stock Market |
| `/st` | Ouvrir l'arbre de compétences |
| `/kit` | Récupérer vos kits de départ gratuits (des kits supplémentaires se débloquent en liant votre compte Discord) |
| `/sell` | Vendre des ressources contre des RP |
| `/pricecheck <item>` ou `/pc <item>` | Vérifier le prix de vente actuel d'un objet (les prix diffèrent selon les mondes) |
| `/vq` ou `/qr` | Ouvrir les carrières virtuelles |
| `/tod` | Voir l'heure actuelle de la journée |
| `/wa` | Ouvrir votre réserve et les Wipe Achievements |
| `/info` | Fenêtre d'information en jeu, y compris une liste de commandes |
| `/wiki` | Affiche une fenêtre d'information |

## Capacités de l'arbre de compétences

La compétence **Orbital Strike** de l'arbre Combat n'est pas déclenchée par une commande. Une fois débloquée, la compétence fait apparaître une **fusée éclairante** dans votre barre d'actions. Lancez la fusée éclairante : la frappe tombe à cet endroit.

> 💡 **Astuce Orbital Strike**
>
> Gardez un emplacement vide dans votre barre d'actions pour que la compétence ait un endroit où faire apparaître la fusée éclairante.

## Associer des commandes à des touches

Les raccourcis clavier de Rust vous permettent de lancer des commandes de chat depuis une touche, au lieu d'ouvrir le chat et de les taper à chaque fois. C'est utile pour les commandes que vous utilisez en permanence, comme revenir au HUB, ouvrir les quêtes, ouvrir les boutiques, acheter du contenu de raid, ou appeler un vélo.

Ouvrez la console F1 et utilisez ce format :

```text
bind key chat.say "/command"
```

Pour les commandes sans espaces, vous pouvez aussi utiliser la forme courte :

```text
bind key chat.say /command
```

Utilisez des guillemets quand la commande contient des espaces, comme `/home base`.

Le raccourci doit fonctionner tout de suite. Pour les raccourcis que vous voulez garder, Facepunch recommande d'exécuter :

```text
writecfg
```

Pour retirer un raccourci plus tard, exécutez :

```text
bind key ""
```

Les touches d'exemple ci-dessous sont choisies pour éviter les raccourcis par défaut courants de déplacement, de combat, de carte, de voix, d'inventaire, de rechargement, d'accroupissement, de sprint et de barre d'actions. Si une touche est déjà utilisée dans votre configuration, changez le nom de la touche avant d'exécuter le raccourci.

Pour les raccourcis de home, remplacez `base` par le vrai nom de votre home, comme `/home 1` ou `/home main`.

| Usage | Commande | Touche suggérée | Exemple de raccourci | Retirer ce raccourci |
|----------|----------|----------|----------|----------|
| Revenir au HUB | `/hub` | Pavé numérique `+` | `bind numpadplus chat.say /hub` | `bind numpadplus ""` |
| Se téléporter au home | `/home <name>` | Pavé numérique `-` | `bind numpadminus chat.say "/home base"` | `bind numpadminus ""` |
| Ouvrir les quêtes | `/q` | Pavé numérique `9` | `bind numpad9 chat.say /q` | `bind numpad9 ""` |
| Ouvrir les carrières virtuelles | `/vq` | Pavé numérique `6` | `bind numpad6 chat.say /vq` | `bind numpad6 ""` |
| Acheter une base de raid | `/buyraid` | Pavé numérique `7` | `bind numpad7 chat.say /buyraid` | `bind numpad7 ""` |
| Acheter un donjon | `/buydungeon` | Pavé numérique `8` | `bind numpad8 chat.say /buydungeon` | `bind numpad8 ""` |
| Ouvrir la boutique / le Stock Market | `/s` | Virgule | `bind comma chat.say /s` | `bind comma ""` |
| Appeler un vélo gratuit | `/toolazytowalk` | Crochet gauche | `bind leftbracket chat.say /toolazytowalk` | `bind leftbracket ""` |
| Ouvrir l'arbre de compétences | `/st` | Crochet droit | `bind rightbracket chat.say /st` | `bind rightbracket ""` |
| Accepter une demande de téléportation | `/tpa` | Point | `bind period chat.say /tpa` | `bind period ""` |

### Exemples pour un clavier plus petit

Si vous n'avez pas de pavé numérique, utilisez plutôt les crochets, la ponctuation ou d'autres touches inutilisées. Ne remplacez que le nom de la touche :

```text
bind leftbracket chat.say /hub
bind rightbracket chat.say "/home base"
bind comma chat.say /s
bind period chat.say /tpa
```

Évitez de remplacer des touches Rust par défaut importantes, sauf si vous êtes sûr de ne pas les utiliser. Par exemple, associer `q` à `/q` peut être pratique, mais cela peut écraser un raccourci Rust normal sur beaucoup de configurations.
