# Befehle (Commands)

Brits PvE Worlds fügt viele eigene Befehle hinzu, die Reisen, Fortschritt, Automatisierung und das Spiel deutlich leichter machen.

## Kurzüberblick

- **Empfohlen für:** Alle Spieler
- **Hauptziel:** Lern die am häufigsten genutzten Befehle.
- **Tipp:** Die meisten Befehle findest du auch im Spiel über **`/info`**.

Alle Befehle tippst du in den Chat. Wenn du einen Befehl ständig nutzt, leg ihn auf eine Taste: siehe **Befehle auf Tasten legen** unten auf dieser Seite.

---

## Wichtige Befehle

Das sind die Befehle, die jeder neue Spieler kennen sollte.

| Befehl | Beschreibung |
|----------|-------------|
| `/hub` | Teleport in den HUB |
| `/w` oder `/worlds` | Öffnet das Weltmenü |
| `/q` oder `/quest` | Öffnet das Quest-Menü |
| `/s` | Öffnet den Shop / Stock Market |
| `/st` | Öffnet den Skillbaum |
| `/kit` | Hol deine kostenlosen Starter-Kits (weitere Kits schaltest du frei, wenn du dein Discord-Konto verknüpfst) |
| `/sell` | Verkaufe Ressourcen für RP |
| `/pricecheck <item>` oder `/pc <item>` | Prüfe den aktuellen Verkaufspreis eines Items (Preise unterscheiden sich zwischen Welten) |
| `/vq` oder `/qr` | Öffnet Virtual Quarries |
| `/tod` | Zeigt die aktuelle Tageszeit |
| `/wa` | Öffnet dein Stash und die Wipe Achievements |
| `/info` | Infofenster im Spiel, inklusive einer Befehlsliste |
| `/wiki` | Zeigt ein Infofenster |

## Fähigkeiten aus dem Skillbaum

Der Skill **Orbital Strike** aus dem Baum Combat wird nicht über einen Befehl ausgelöst. Sobald er freigeschaltet ist, spawnt der Skill eine **Flare** in deiner Hotbar. Wirf die Flare, und der Schlag landet an dieser Position.

> 💡 **Tipp zu Orbital Strike**
>
> Halt einen Slot in deiner Hotbar frei, damit der Skill die Flare irgendwo spawnen kann.

## Befehle auf Tasten legen

Rust-Tastenbelegungen lassen dich Chat-Befehle über eine Taste ausführen, statt jedes Mal den Chat zu öffnen und sie zu tippen. Das ist nützlich für Befehle, die du ständig drückst, zum Beispiel zurück in den HUB, Quests öffnen, Shops öffnen, Raid-Inhalt kaufen oder ein Fahrrad rufen.

Öffne die F1-Konsole und nutze dieses Format:

```text
bind key chat.say "/command"
```

Bei Befehlen ohne Leerzeichen geht auch die kürzere Form:

```text
bind key chat.say /command
```

Nutze Anführungszeichen, wenn der Befehl Leerzeichen enthält, zum Beispiel `/home base`.

Die Belegung sollte sofort funktionieren. Für Belegungen, die du behalten willst, empfiehlt Facepunch:

```text
writecfg
```

Um eine Belegung später zu entfernen:

```text
bind key ""
```

Die Beispiel-Tasten unten sind so gewählt, dass sie übliche Standardbelegungen für Bewegung, Kampf, Karte, Sprache, Inventar, Nachladen, Ducken, Sprint und Hotbar meiden. Wenn eine Taste bei dir schon belegt ist, änder den Tastennamen, bevor du den Bind ausführst.

Bei Home-Binds ersetz `base` durch deinen echten Home-Namen, zum Beispiel `/home 1` oder `/home main`.

| Nutzen | Befehl | Vorgeschlagene Taste | Bind-Beispiel | Diese Belegung entfernen |
|----------|----------|----------|----------|----------|
| Zurück in den HUB | `/hub` | Nummernblock `+` | `bind numpadplus chat.say /hub` | `bind numpadplus ""` |
| Nach Hause teleportieren | `/home <name>` | Nummernblock `-` | `bind numpadminus chat.say "/home base"` | `bind numpadminus ""` |
| Quests öffnen | `/q` | Nummernblock `9` | `bind numpad9 chat.say /q` | `bind numpad9 ""` |
| Virtual Quarries öffnen | `/vq` | Nummernblock `6` | `bind numpad6 chat.say /vq` | `bind numpad6 ""` |
| Eine Raid-Base kaufen | `/buyraid` | Nummernblock `7` | `bind numpad7 chat.say /buyraid` | `bind numpad7 ""` |
| Einen Dungeon kaufen | `/buydungeon` | Nummernblock `8` | `bind numpad8 chat.say /buydungeon` | `bind numpad8 ""` |
| Shop / Stock Market öffnen | `/s` | Komma | `bind comma chat.say /s` | `bind comma ""` |
| Ein kostenloses Fahrrad rufen | `/toolazytowalk` | Linke Klammer | `bind leftbracket chat.say /toolazytowalk` | `bind leftbracket ""` |
| Skillbaum öffnen | `/st` | Rechte Klammer | `bind rightbracket chat.say /st` | `bind rightbracket ""` |
| Teleport-Anfrage annehmen | `/tpa` | Punkt | `bind period chat.say /tpa` | `bind period ""` |

### Beispiele für kleinere Tastaturen

Wenn du keinen Nummernblock hast, nutze stattdessen Klammern, Satzzeichen oder andere freie Tasten. Ersetz nur den Tastennamen:

```text
bind leftbracket chat.say /hub
bind rightbracket chat.say "/home base"
bind comma chat.say /s
bind period chat.say /tpa
```

Ersetz wichtige Standard-Tasten von Rust nur, wenn du sicher bist, dass du sie nicht nutzt. `q` auf `/q` zu legen kann praktisch sein, überschreibt auf vielen Setups aber eine normale Rust-Belegung.
